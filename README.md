# QuickBite Agentic Analytics

Agentic AI prototype for QSR business insights. Business users ask questions in natural language and receive data-backed answers over the QuickBite dataset.

## Project structure

```
illuminity_project/
├── data/
│   ├── raw/                    # Source Excel dataset
│   └── qsr.duckdb              # Generated by seed_db.py
├── backend/
│   ├── agents/                 # Orchestrator, planner, analyst, insight
│   ├── tools/                  # SQL and analytics tools
│   ├── data/                   # Schema and data loading
│   └── main.py                 # FastAPI entry point
├── frontend/                   # Chat UI (Phase 5)
├── scripts/
│   └── seed_db.py              # Load Excel → DuckDB (Phase 2)
├── docs/
│   └── ARCHITECTURE.md
└── requirements.txt
```

## Quick start (Windows)

**Terminal 1 — Backend** (must run first):
```bash
cd "d:\D files\illuminity_project"
start-backend.bat
```
Or:
```bash
.venv\Scripts\activate
python scripts/start.py
```

**Terminal 2 — Frontend**:
```bash
cd "d:\D files\illuminity_project"
start-frontend.bat
```
Or:
```bash
cd frontend
npm run dev
```

Open http://localhost:5173/app/

> Backend must be on port **8000** before frontend works. If you see "DB Missing" or "Agents Need API Key", the backend is not running or `.env` was not loaded — always start from the **project root**, not the `backend` folder.

## Setup

### 1. Create virtual environment

```bash
cd "d:\D files\illuminity_project"
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Environment variables

Create a `.env` file in the project root:

```env
# Recommended — Groq free tier
LLM_PROVIDER=groq
GROQ_API_KEY=your_groq_key_here

# Or Google Gemini
# LLM_PROVIDER=gemini
# GOOGLE_API_KEY=your_gemini_key_here

# Or OpenAI
# LLM_PROVIDER=openai
# OPENAI_API_KEY=your_key_here
```

Get keys: [Groq](https://console.groq.com) · [Gemini](https://aistudio.google.com/apikey)

### Database

**Local (default):** DuckDB — no setup needed after seeding.

```bash
python scripts/seed_db.py
```

**Deploy:** PostgreSQL — set `DATABASE_URL` in `.env` and seed:

```bash
python scripts/seed_postgres.py
```

See `docs/DEPLOY.md` for Render/Railway deployment steps.

### 3. Seed the database

```bash
python scripts/seed_db.py
```

This loads the Excel file into `data/qsr.duckdb` and creates enriched views.

### 4. Verify backend starts

```bash
uvicorn backend.main:app --reload
```

Open http://127.0.0.1:8000/health — you should see `"database_present": true`.
Open http://127.0.0.1:8000/schema — schema metadata for agents.

### 5. Ask a question (Phase 3)

```bash
python scripts/ask.py "What were the total revenue, orders, and average order value for the last 3 months?"
```

Or via API:

```bash
curl -X POST http://127.0.0.1:8000/ask -H "Content-Type: application/json" -d "{\"question\":\"Top 5 stores by revenue\"}"
```

### 6. Validate reference questions (Phase 4)

```bash
python scripts/validate_questions.py
```

Benchmark API (no LLM required):

```bash
curl http://127.0.0.1:8000/benchmarks
curl http://127.0.0.1:8000/examples
```

### 7. Launch chat UI (Phase 5)

**Dev mode (recommended for demo):**

```bash
# Terminal 1
uvicorn backend.main:app --reload

# Terminal 2
cd frontend
npm install
npm run dev
```

Open http://localhost:5173/app/

**Production-style (backend serves built UI):**

```bash
cd frontend
npm install
npm run build
cd ..
uvicorn backend.main:app --reload
```

Open http://127.0.0.1:8000/app/

See `docs/DEMO.md` for a 5-minute demo script.

## Dataset

- **Source:** `data/raw/QSR_Agentic_Insights_Dataset.xlsx`
- **Brand:** QuickBite
- **Coverage:** Aug 2025 – Jul 2026
- **Tables:** Orders, Order_Details, Store_Master, Product_Master, Customer_Master, Promotions, Calendar

## Supported questions (target)

1. Total revenue, orders, and AOV for the last 3 months
2. Top 5 and bottom 5 stores by revenue
3. Revenue and AOV by channel
4. Top 5 SKUs by quantity and revenue
5. Cities with revenue decline over the last 3 months
6. Weekend vs weekday performance
7. Festive vs normal period performance
8. Stores with consistent decline and key reasons
